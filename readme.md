This plugin enables you to add ACH field type to Gravity Forms.

== Description ==


[Gravity Forms](https://www.gravityforms.com/) is one of the oldest most advanced custom form plugins in the WordPress sphere. Powering over a million websites, Gravity Forms allows you to quickly and easily integrate with a variety of third party services with a fantastic collection of add-ons.


**Requirements**
-------
* [Gravity Forms](https://www.gravityforms.com/) plugin 2.3.0 or later.
* Any compatible payment gateway plugin that supports ACH. (See current list below).

**Extend, Contribute, Integrate**
-------
The plugins currently compatible with the ACH field add-on are (more to be added later):

1. [USAePay Gateway For Gravity Forms (Advanced Version)](https://wpgateways.com/products/usaepay-gateway-gravity-forms/).
2. [BluePay Gateway For Gravity Forms (Advanced Version)](https://wpgateways.com/products/bluepay-gateway-gravity-forms/). (In progress)

For custom integration with your WordPress website, please [contact us here](https://wpgateways.com/support/custom-payment-gateway-integration/).

== Installation ==

1. Install the Gravity Forms ACH Field Type plugin from [this link](https://bitbucket.org/gateways/gf-ach-field/downloads/).
2. Upload `gravityforms-ach-field` folder/directory to the `/wp-content/plugins/` directory
3. Activate the plugin (WordPress -> Plugins).
4. Now go to the forms page (WordPress -> Forms) and create/edit a form.
5. Find "ACH" type field under "Pricing Fields" section and setup condition and labels if required.
6. Install a compatible payment gateway plugin (see aboe for current list).
7. Follow the instructions therein on how to setup feeds that integrate with ACH type field.
